AI Chat Exporter — 本地演示页 / offline demo

这个页面内置了一段模拟对话，用来在不登录任何站点的情况下验证导出流程。
直接用 Chrome 打开本文件（双击即可），右下角会出现导出按钮；也可以先在 chrome://extensions 里以“加载已解压的扩展程序”方式安装本扩展， 再回到本页点击浏览器工具栏图标。
This page bundles a fake conversation so you can verify extraction, Markdown, JSON, HTML and PDF export without signing in anywhere.
我
帮我给这个导出工具写一段使用说明，要包含安装步骤和注意事项。
助手

安装分成两步：

  1. 打开 chrome://extensions，打开右上角“开发者模式”
  2. 点击“加载已解压的扩展程序”，选择本仓库目录

注意事项：

  • 安装后需要刷新已打开的对话页面
  • 图片导出会连同 Markdown 一起打包成 ZIP
  • PDF 走浏览器打印对话框，选择“另存为 PDF”
