AI Chat Exporter — UI 预览

这个页面同步渲染面板（不依赖内容脚本的异步启动），用于生成 docs/images/ 里的截图： #panel 打开面板、#range=2-4 打开并填入范围、#diag 展开结构诊断。
我
帮我给这个导出工具写一段使用说明，要包含安装步骤和注意事项。
助手

安装分成两步：

  1. 打开 chrome://extensions，打开右上角"开发者模式"
  2. 点击"加载已解压的扩展程序"，选择本仓库目录

注意事项：

  • 安装后需要刷新已打开的对话页面
  • 图片导出会连同 Markdown 一起打包成 ZIP
  • PDF 走浏览器打印对话框，选择"另存为 PDF"
